# Claude Code memory transfer

Snapshot of the CalmCarry project memory from the Mac, exported 2026-07-03.

These are Claude Code auto-memory files. They don't do anything sitting in the
repo — they need to be installed into Claude Code's memory directory on this
machine.

## To import (instructions for Claude Code on a new machine)

Copy every `.md` file in this folder **except this README** into your
auto-memory directory for this project (the path listed in your system prompt,
e.g. `~/.claude/projects/<project-slug>/memory/`), overwriting what's there.
Keep `MEMORY.md` as the index. After copying, confirm to the user which
memories were installed.

## To import (manual)

1. Open a terminal in this project folder and run `claude`.
2. Ask: "Import the memory files from the claude-memory/ folder into your
   memory directory, then list what you imported."
